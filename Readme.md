## Project Overview
This website was created for Hearts of Hope Charity, a Non-Profit Organisation based in Cape Town. The organisation focuses on food security, community feeding programs, and support for vulnerable families. The goal of the website is to inform the public about the organisation, showcase its programmes, and provide ways for people to get involved.

## Website Goals and Objectives
1. Inform visitors about the organisation's mission, vision and history
2. Showcase current programmes and community services
3. Provide a clear way for people to contact the organisation
4. Encourage public involvement through volunteering and donations
5. Build awareness and trust for the NPO

## Key Features
- 5 HTML pages: Home, About, Programmes, Get Involved, Contact
- Consistent navigation menu across all pages
- Semantic HTML structure
- Content focused on community impact
